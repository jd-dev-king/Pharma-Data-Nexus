# Pharma Data Nexus 3D
## Enterprise Pharmaceutical Manufacturing Simulation for the EES Portfolio Universe

Pharma Data Nexus 3D is an interactive Three.js experience that visualizes a modern pharmaceutical manufacturing data ecosystem. Instead of static charts, visitors explore a holographic command center where Manufacturing Execution (MES), Laboratory Information Management (LIMS), Quality Management (QMS), Computerized Maintenance Management (CMMS), and ALCOA+ audit systems are represented as animated 3D holograms connected to a central PostgreSQL database.

## Highlights

- Interactive Three.js 3D environment
- Holographic server towers and floating database displays
- PostgreSQL enterprise data model (38 normalized tables)
- Simulated pharmaceutical manufacturing workflows
- FDA cGMP-inspired ALCOA+ data integrity concepts
- Clickable Architecture, Project Details, and Tables & SQL panels
- Animated data streams between enterprise systems
- Responsive glassmorphism interface
- GitHub Pages compatible
